## About me

I'm a project manager who enjoys connecting business needs with hands-on technical work. My focus is on AI integrations, useful automation, and making complex systems easier for people to adopt.

I bring a practical perspective to projects: define the problem, build a clear workflow, test it, and document what matters.

## What I work on

- **AI integrations** — connecting assistants to real applications through APIs and the Model Context Protocol (MCP).
- **Project delivery** — translating requirements into actionable plans, coordinated testing, and clear documentation.
- **Workflow automation** — reducing repetitive work and making everyday tools more useful.
- **Partner enablement** — helping teams understand, evaluate, and adopt technical products.

## Featured project

### [IvedaAI MCP Server](https://github.com/WillORepo/ivedaAI-mcp-server)

An MCP server that connects compatible AI assistants to the IvedaAI video analytics API, supporting camera management, alerts, analysis jobs, and search workflows.

Built with **TypeScript** and **Node.js**, with a read-only mode, configuration guidance, and documented tool workflows.

[View repository](https://github.com/WillORepo/ivedaAI-mcp-server) · [Usage guide](https://github.com/WillORepo/ivedaAI-mcp-server/blob/main/docs/USAGE.md) · [Design notes](https://github.com/WillORepo/ivedaAI-mcp-server/blob/main/docs/DESIGN.md)
